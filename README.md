# AI Workplace Assistant

Build a modern responsive SaaS web app called AI Workplace Productivity Assistant.

CORE FEATURES

Implement:

Login Page — professional login screen with email/username and password, show/hide password, remember me, validation and login/logout flow. Use a simple demo authentication if no backend is connected.

Smart Email Generator — Formal, Friendly and Persuasive tones; editable AI output.

Meeting Notes Summarizer — summary, Action Items, Decisions and Deadlines.

AI Task Planner — daily/weekly schedules and task prioritization.

AI Research Assistant — topic summaries, insights and recommendations.

THANDI — Your AI Workplace Assistant — chatbot, chat history, suggested prompts, loading state and clear conversation.

WORKPLACE FEATURES

Add:

Staff directory and staff search

Staff-to-staff interaction/messaging

Availability: Available, Away, Busy

Activity Tracker recording meaningful actions with activity type, description, exact date/time and relative time such as “Just now” or “5 minutes ago”

Generate timestamps automatically using actual local/system time. Never hard-code timestamps.

UI

Create:

Professional dashboard

Sidebar navigation

Global header with app name, page title, Help, profile and availability

Responsive desktop/tablet/mobile design

Input and AI output sections

Professional SaaS styling

Global footer with app name, current year, Responsible AI, Help, Privacy and Settings

Help modal explaining the application, tools, THANDI, availability, Activity Tracker and Responsible AI.

PRIORITY

Build in this order:

Login/logout and navigation

Core AI tools and THANDI

Staff search and interaction

Availability and Activity Tracker

Header, Help and Footer

Responsive/accessibility/error-handling QA

Final visual polish

IMPORTANT

Prioritize functionality over aesthetics. Do not create dead buttons, fake interactions or hard-coded timestamps. Fix console errors and broken interactions.

Include a Responsible AI disclaimer: AI-generated content must be reviewed by users before workplace use.
