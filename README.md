# AI Workplace Productivity Assistant

A modern, responsive SaaS-style workplace productivity platform designed to help professionals streamline everyday tasks using AI.

The application brings together AI-powered productivity tools, workplace collaboration, task management, research assistance, and an interactive AI workplace assistant called **THANDI** in one unified dashboard.

> **Responsible AI:** AI-generated content should always be reviewed and verified by the user before being used for workplace communication, decisions, or other professional purposes.

---

## ✨ Features

### 🔐 Authentication

* Professional login interface
* Email/username and password authentication
* Show/hide password
* Remember me option
* Form validation
* Login and logout flow
* Demo authentication when no backend is configured

### ✉️ Smart Email Generator

Generate professional workplace emails using different communication styles:

* Formal
* Friendly
* Persuasive

Generated content can be reviewed and edited before use.

### 📝 Meeting Notes Summarizer

Transform lengthy meeting notes into structured information:

* Meeting summary
* Action items
* Decisions
* Deadlines

### 📅 AI Task Planner

Create organized daily or weekly schedules with AI-assisted prioritization.

The planner helps users identify important tasks and structure their workload more effectively.

### 🔎 AI Research Assistant

Research workplace topics and receive:

* Topic summaries
* Key insights
* Recommendations
* Structured information for easier understanding

### 🤖 THANDI — Your AI Workplace Assistant

**THANDI** is the application's interactive AI workplace assistant.

Features include:

* Conversational AI interface
* Chat history
* Suggested prompts
* Loading states
* Clear conversation functionality
* Workplace productivity assistance
* Activity tracking for AI interactions

### 👥 Workplace Collaboration

The platform includes workplace collaboration functionality with:

* Staff directory
* Staff search
* Staff-to-staff interaction
* Workplace messaging
* User availability status

Availability options:

* 🟢 Available
* 🟡 Away
* 🔴 Busy

### 📊 Activity Tracker

The Activity Tracker provides an audit-style view of meaningful user activity.

Each activity records:

* Activity type
* Description
* Date
* Exact timestamp
* Relative timestamp

Examples:

> Just now
> 5 minutes ago
> 1 hour ago

Timestamps are generated automatically using the user's local/system time rather than hard-coded values.

## 🎯 Project Purpose

The goal of this project is to demonstrate how AI can be integrated into everyday workplace workflows to reduce repetitive administrative tasks and improve productivity.

Instead of using AI as a standalone chatbot, the application places AI directly inside common workplace activities such as:

* Writing emails
* Summarizing meetings
* Planning tasks
* Researching information
* Communicating with colleagues
* Tracking workplace activity

---

## 💡 Innovation

The application combines **AI productivity tools and workplace collaboration** within a single platform.

A key feature is **THANDI**, which acts as a central AI workplace assistant while the Activity Tracker provides visibility into user interactions and productivity actions.

The combination creates a more practical workplace environment rather than simply providing a basic AI chat interface.

---

## 🛡️ Responsible AI

AI-generated information can contain errors, omissions, or misleading information.

Users should:

* Review AI-generated content before using it
* Verify important information
* Avoid entering confidential or sensitive workplace information
* Use human judgment when making professional decisions
* Treat AI suggestions as assistance rather than unquestionable facts

AI should support workplace productivity — **not replace human accountability.**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local development URL provided by Vite in your browser.
